04 / Start locally

Your databases. Your workspace.

The desktop app connects to your databases locally. This website introduces the product; it does not connect to databases or run SQL.

01

Install on Windows

The desktop app is packaged as a Windows MSI. Install it, launch dbfox and choose your interface language.

A public installer is not available from this page yet. The download link will appear here after the release is verified.

02

Add a connection

Choose a database engine and enter its connection details. Test the connection, open a database and inspect the object tree. Start with a read-only account.

03

Set up MCP separately

MCP requires the standalone dbfox-mcp executable. If you have access to the source repository, build it with:

cargo build -p dbfox-mcp --release

Point your MCP client at the built executable using stdio. The desktop MSI alone does not configure MCP; a public standalone download is not yet linked here.

05 / FAQ

Before you get started.

Do I need a dbfox cloud account?

No dbfox cloud account is required for the local workspace. You connect using your own database credentials. If you connect an external AI assistant, its own data handling and account requirements apply.

Can I run queries on every supported database?

Query execution currently supports PostgreSQL and MySQL. Redshift and ClickHouse support object/DDL exploration and SQL dialect conversion. Cancelling a query does not undo statements that have already committed.

Does migration guarantee an identical result?

No. Database engines differ in types and semantics. Inspect preflight mappings and warnings, test on non-production data and review the result report. dbfox does not promise real-time CDC or zero-downtime migration.

Can an AI assistant write data through MCP?

The current MCP tools expose read-only exploration and migration planning, not database writes or migration execution. Read-only queries are limited to PostgreSQL and MySQL. Use database permissions to enforce access limits.

Where are the macOS and Linux installers?

The current desktop packaging targets Windows MSI. This page does not offer verified macOS or Linux installers. Public Windows and standalone MCP downloads will be added when available.
