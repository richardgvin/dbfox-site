查结构，转 SQL，
看清计划再迁移。

dbfox 是运行在本机的多数据库工作台，无需云账号。一次接入 15 种数据库，统一查看 DDL、安全执行查询；离线转换 SQL 方言，清晰对照每一处改写与列血缘；跨库迁移前先做只读预检，审阅类型映射与风险，再放心动手。

面对多种数据库，每一步都有据可依。

专为同时维护多套数据库的开发者、DBA 和数据工程师打造。下面三项能力既可单独使用，也能串成一条完整的跨库工作流：先摸清表结构，再消化方言差异，最后带着清晰计划执行迁移。

结构与查询，一屏看清。

所有连接、数据库、模式与对象收拢在同一棵对象树中。点选表即可查看 DDL 与约束，旁开标签页即可编写 SQL——编辑器基于已加载元数据提供补全、离线语法诊断与重命名，大结果集逐页增量读取，减少误操作与来回切换。

  • 支持 12 种 SQL 数据库的表/视图 DDL 查看，以及 MongoDB、Redis、Elasticsearch 专用目录浏览
  • 单条查询按页增量读取，翻页与导出 CSV 直接复用缓存结果，不再重复执行 SQL
  • 编写阶段即提示语法问题；执行 DELETE、无 WHERE 的 UPDATE 或改列类型等高风险语句前强制确认

SQL 改了哪里，一眼看懂。

支持 PostgreSQL、MySQL、SQL Server、Snowflake、Oracle、DuckDB 等 10 种主流 SQL 方言互转。转换结果与原语句并排对比，函数替换、引号变化与结构差异一目了然；同步生成列血缘，逐列追溯跨 CTE、子查询、JOIN 与 UNION 的字段来源。

  • 纯本地解析，不执行语句，也无需提前连接数据库，随时贴入即可分析与转换
  • 目标方言无法表达的语法、无法确定的血缘来源均会显式标出，不静默丢弃

先审预检计划，再启动迁移。

选定源库、目标库与待迁表后，dbfox 会先执行只读预检：逐列给出目标类型映射，标出目标冲突，并按 L1 无损、L2 有损、L3 不可映射分级呈现风险。所有有损映射与不可映射项必须由你明确决策后，才会执行一次性结构与数据迁移。

  • 迁移表结构、主键、索引、唯一约束及表数据，完成后逐表校验目标行数
  • 视图、外键、触发器等未迁移对象均在计划中单独列出；预检计划与执行报告均可导出为 JSON 或 Markdown

把上下文交给 AI，把写入权留给自己。

将支持 MCP 的 AI 助手接入 dbfox，它即可复用你本机已保存的连接来读结构、做只读查询、校验或转换 SQL，并起草迁移计划。数据库凭据始终留在本地，写入与迁移执行不在工具清单中，最终操作依然由你在工作台确认。

安装后，三步即可上手

  1. 建立首个连接

    点击“新建连接”选择数据库类型，或直接粘贴连接串与连接信息，表单会自动拆解主机、端口和库名。初次试用建议从只读账号开始。

  2. 浏览结构与数据

    展开左侧对象树，点击任意表即可查看 DDL 与索引；通过右键菜单选择“预览数据（LIMIT 100）”快速抽查内容。

  3. 不连库也能试用

    直接打开顶栏的“SQL 转换”，贴入任意 SQL 并选择源/目标方言，立刻体验离线方言改写、代码对比与列血缘分析。

开始前，常见问题速览

使用 dbfox 需要注册云账号吗？

不需要。dbfox 完全运行在你的本机，直接使用你的数据库凭据直连目标实例，不经过第三方云端中转。连接档案保存在本地数据目录，密码经加密存储（密钥位于同目录，请像保管凭据一样妥善保护）。如接入外部 AI 助手，其账号与数据隐私策略由对应服务商决定。

15 种数据库都支持执行查询吗？

支持方式按引擎类型区分：12 种 SQL 数据库（PostgreSQL、MySQL、MariaDB、SQL Server、SQLite、Snowflake、DuckDB、DuckLake、Oracle、Db2、Redshift、ClickHouse）支持执行 SQL；Elasticsearch 支持只读 SQL 及 _search/_count/GET 检索请求；MongoDB 与 Redis 支持执行原生命令（包含当前账号权限允许的写操作）。请注意，中途取消查询无法回滚已经提交的语句。

数据库迁移能否保证两端完全一致？

不能做出绝对一致的承诺。不同数据库在数据类型与约束语义上存在天然差异，且视图、外键、触发器等对象目前不在迁移范围内。迁移属于一次性结构与数据拷贝（不提供实时 CDC 或零停机切换），建议先仔细审阅预检映射与警告，在非生产环境验证后再核对执行报告。

AI 助手会通过 MCP 修改或删除我的数据吗？

不会。dbfox MCP 的 15 个工具全部限定为只读探索、只读查询、SQL 校验/分析与迁移规划，不包含任何写操作或迁移执行工具；只读查询会经过语法层只读校验并在只读事务中回滚执行（当前支持 PostgreSQL、MySQL、MariaDB、SQL Server 与 SQLite，暂不支持 Snowflake 和 Elasticsearch）。你也可以按连接关闭 AI 访问，并务必配合只读数据库账号守住权限边界。

是否支持 macOS 和 Linux？

桌面端安装程序目前仅提供 Windows x64 版本。Linux 用户可通过 Docker Compose 配置包（linux/amd64 镜像）启动同一套完整工作台，在桌面浏览器中使用。目前暂无 macOS 或 Linux 桌面安装包。
